# Rechnungen als CSV exportieren

Sie exportieren Ihre Rechnungen eines Zeitraums als CSV-Datei.

Neu:
```markdown
# Rechnungen als CSV exportieren

Sie exportieren die Rechnungen eines Zeitraums als CSV-Datei.

## Voraussetzungen

- Sie sind Admin.

## Schritte

1. Öffnen Sie **Einstellungen > Abrechnung**.
2. Wählen Sie den Zeitraum. Es sind höchstens 12 Monate möglich.
3. Wählen Sie **CSV exportieren**.
```
